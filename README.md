# SalesDataAnalysis
Analyzed sales data using SQL Server to identify revenue trends, top-performing products, categories, and regions. Used SELECT, WHERE, GROUP BY, HAVING, ORDER BY, aggregate functions, and filtering to generate actionable business insights. 🚀
# Sales Data Analysis using SQL

## Project Overview
Analyzed sales data using SQL Server to identify revenue trends,
top-performing categories, and regional performance.

## Tools Used
- SQL Server
- SQL Server Management Studio (SSMS)
- Excel/CSV

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- COUNT
- SUM
- AVG
- MIN / MAX
- LIKE

## Key Analysis
- Total revenue
- Total transactions
- Revenue by category
- Revenue by region
- Top-performing products
- Highest-value transactions
